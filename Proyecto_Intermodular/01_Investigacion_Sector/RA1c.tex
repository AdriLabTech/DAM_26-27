\section{Objetivo y metodolog\'ia}
Se recogen 11 ofertas de empleo reales de desarrollo de software en Espa\~na, publicadas en 6 fuentes distintas (InfoJobs, StudentJob, Iberempleos, Ticjob, CazVid y la web de empleo de una empresa). Se extraen las palabras clave y los requisitos t\'ecnicos m\'as comunes y con ellos se redacta una descripci\'on estandarizada de 6 roles, con la plantilla de perfil de puesto del enunciado.

Todas las ofertas se consultaron el 14 de octubre de 2026. Algunas ya estaban cerradas o inactivas en esa fecha y se indica en la tabla de fuentes. De las tres ofertas de InfoJobs solo se pudo leer el extracto que muestra el buscador (la p\'agina bloquea la descarga), as\'i que de ellas solo se usan los datos de ese extracto. Lo que una oferta no dice se marca como \nv{} y no se ha completado con suposiciones.

\subsection*{Lectura}
\begin{itemize}
\item El n\'ucleo \textbf{Java + Spring Boot + Git + Jenkins} aparece en casi la mitad de las ofertas y coincide con el ciclo DAM.
\item \textbf{Angular} es el framework de frontend citado en las ofertas de frontend y full stack (O4, O5, O6). React y Vue solo aparecen como deseables en O5.
\item \textbf{Mensajer\'ia y microservicios}: Kafka en 3 ofertas (O2, O3, O4) y microservicios en O3 y O4.
\item \textbf{DevOps}: Docker (O2, O9), Kubernetes (O8, O9), Terraform y Azure DevOps (O8), Helm (O9).
\item \textbf{Calidad}: SonarQube (O3, O4), TDD/BDD (O3), Selenium y JIRA (O10).
\item \textbf{Base de datos}: PostgreSQL (O3, O11), Oracle y MongoDB (O3), JPA/Hibernate (O1, O4).
\item \textbf{Ingl\'es} es requisito en 6 de 11 ofertas (O1, O2, O6, O7, O8, O9) y deseable en O3 y O4; el nivel pedido llega a avanzado (O1).
\item \textbf{Habilidades blandas} expl\'icitas (pocas): autonom\'ia (O2, O8), proactividad (O2, O8), comunicaci\'on y colaboraci\'on (O8), trabajo en equipo \'agil (O5, O10).
\end{itemize}

\section{Conclusiones}
\begin{itemize}
\item El perfil m\'as demandado en la muestra es el \textbf{desarrollador Java con Spring Boot} (5 de 11 ofertas), con Git y Jenkins como compa\~neros habituales.
\item \textbf{Angular} es la opci\'on de frontend de las ofertas analizadas; combinada con Spring Boot forma el perfil full stack mejor pagado de la muestra (33.000--41.000 \texteuro{}).
\item Las ofertas junior y mid son las que publican sueldo (25.000--41.000 \texteuro{}); las senior no.
\item \textbf{Ingl\'es} y \textbf{titulaci\'on universitaria} son requisitos transversales, m\'as repetidos que cualquier tecnolog\'ia salvo Git.
\item Java/Spring, Angular y SQL, el ciclo DAM, cubren los roles 1, 2, 3 y 6; DevOps y QA piden a\~nadir Docker, CI/CD y pruebas autom\'aticas.
\end{itemize}

\section{Limitaciones}
La muestra es peque\~na (11 ofertas, 3 de la misma empresa en Ticjob) y no es representativa del mercado. Varias ofertas estaban cerradas o inactivas el 14 de octubre de 2026. Las tres de InfoJobs se leyeron solo en el extracto del buscador. Las cifras son salarios brutos publicados, no medias de mercado. Los requisitos de las ofertas son autodeclarados y los perfiles son una s\'intesis propia; los campos que ninguna oferta cubre se marcan como \nv. No se ha usado LinkedIn ni Indeed porque no se pudo acceder a ofertas concretas.

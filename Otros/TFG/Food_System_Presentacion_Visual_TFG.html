Un producto, muchas instalaciones

Cada establecimiento instala su propia versión, elige qué módulos ofrece y actualiza cuando quiere. GitHub distribuye el software; los datos son siempre del negocio. Nombre de trabajo y datos de ejemplo: todo es maqueta.

Módulos en vivo

La app de escritorio define qué ofrece la web. Cada cambio se guarda en el backend y llega a los clientes por WebSocket, sin recargar.

Prueba a desactivar «Reservas online» o «Pedidos online» en la app y mira cómo cambia la web. Pedidos avisa de que también desactiva el reparto.

Actualizaciones

Cada release lleva un manifest que el sistema lee para decidir qué mostrar. Nada se instala hasta que el administrador lo confirma, y si algo falla se vuelve a la versión anterior.

Pulsa «Actualizar» en la app para ver el proceso paso a paso.

App de escritorio

El panel del administrador. Las secciones de módulos desactivados se atenúan en el menú y muestran un aviso.

Web de clientes

Una sola web que se construye a partir de la configuración del establecimiento: menús, rutas y flujos aparecen o desaparecen según los módulos activos.

Maqueta generada a partir de la conversación sobre el TFG. Los nombres, precios y cifras son de ejemplo.

# 📚 DAM – Segundo Curso (DAMP)

Este repositorio recopila los **ejercicios, prácticas, proyectos y trabajos de interés** que realizo durante el segundo año del Grado Superior de **Desarrollo de Aplicaciones Multiplataforma (DAMP)**.

El objetivo es mantener un registro organizado de mi actividad durante el curso, conservar aquellos ejercicios que considero relevantes y documentar mi **evolución técnica a lo largo del segundo año**.

---

## 🧠 Objetivos del repositorio

* 📂 Centralizar los ejercicios y prácticas de interés realizados durante el curso
* 🧪 Conservar proyectos y ejercicios relevantes de los diferentes módulos
* 📈 Documentar mi evolución y aprendizaje
* 🗂️ Mantener una estructura organizada por módulos y materias
* 💼 Construir una base de código que pueda servir como referencia para futuros proyectos y portfolio
* 🔍 Poder revisar, mejorar y comparar mi trabajo a medida que avance el curso

---

## 🗂️ Estructura del repositorio

El repositorio se organiza principalmente por **módulos**, dentro de los cuales se agrupan los diferentes ejercicios y proyectos realizados durante el curso.

La estructura irá evolucionando conforme avance el curso y se incorporen nuevos módulos, ejercicios y proyectos.

No todos los ejercicios realizados durante el curso tienen por qué aparecer en este repositorio. La intención es conservar principalmente aquellos que resulten **interesantes, representativos o útiles como referencia**.

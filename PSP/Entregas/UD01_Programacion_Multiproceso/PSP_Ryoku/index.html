Fundamentos
03

Tres conceptos que
no se confunden.

A // Estático

Programa

El objeto estático

  • Conjunto de instrucciones ejecutables directamente por una máquina.
  • Se almacena en un fichero binario, en un medio secundario.
B // Dinámico

Proceso

La entidad dinámica

  • Instancia de un programa en ejecución.
  • Usa memoria, procesador y dispositivos de E/S.
C // Segundo plano

Servicio

Atiende a otros

  • Proceso que presta servicio a otros, del mismo equipo o en red.
  • Corre en segundo plano, sin usuario; lo inicia el SO en el arranque.

Ejecutar un programa = crear un proceso. Un servicio es un proceso que permanece activo para atender a otros.

Concurrencia
09

Concurrencia:
ventajas y coste.

Procesos que se ejecutan simultáneamente en un intervalo de tiempo: simultaneidad real (multiprocesador) o simulada (un procesador). Es también el conjunto de técnicas para que varios procesos cooperen.

+ Ventajas
  • Más rendimiento: la CPU pasa a otro proceso si el actual espera E/S.
  • Menor tiempo de respuesta: el tiempo se reparte entre todos.
− Inconvenientes
  • Sincronización y comunicación más difíciles de implementar.
  • La sobrecarga puede anular la mejora de rendimiento.
  • En sistemas distribuidos, la red puede ser cuello de botella.
Concurrencia
10

Tres formas de ejecutar
varios procesos a la vez.

  • Concurrente. Simultaneidad real o simulada, en uno o varios procesadores.
  • Paralela. Ejecución en varios procesadores de un mismo equipo.
  • Distribuida. Procesos repartidos por una red de equipos.

Java
18

Decoradores sobre
los flujos del proceso.

Lectura

Process p = pbuilder.start();
BufferedReader out = new BufferedReader(
  new InputStreamReader(
    p.getInputStream()));
String linea;
while ((linea = out.readLine()) != null) {
  System.out.println("> " + linea);
}
out.close();

readLine() devuelve null al no quedar líneas.

Escritura

PrintWriter toProcess = new PrintWriter(
  new BufferedWriter(
    new OutputStreamWriter(
      p.getOutputStream(), "UTF-8")),
  true);

toProcess.println("Enviar al hijo");

Con autoflush, cada línea llega al hijo al instante.

Dos procesos en paralelo,
cada uno a su fichero.

ProcessBuilder pb1 = new ProcessBuilder("sh", "-c", "ls");
pb1.redirectOutput(new File("output_ls.txt"));
Process process1 = pb1.start();   // idem con uname -a

int exitCode1 = process1.waitFor();
int exitCode2 = process2.waitFor();

Arrancan sin esperarse y trabajan a la vez; waitFor() los sincroniza y recoge sus códigos.

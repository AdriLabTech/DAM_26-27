# 🧮 MathGame

**Juego de matemáticas por consola escrito en C#.**

MathGame genera operaciones al azar, comprueba tus respuestas y guarda los resultados de la sesión para que puedas comparar tus partidas.

## ✨ Funciones

- Sumas, restas, multiplicaciones y divisiones exactas.
- Partidas de 5 preguntas con puntuación y revisión de fallos.
- Historial de partidas, operaciones y estadísticas.
- Validación de las respuestas introducidas por consola.

## 🚀 Ejecución

Necesitas tener instalado el **SDK de .NET 10**.

```bash
dotnet run --project MathGame
```

> 💾 El historial se mantiene en memoria mientras el programa siga abierto.

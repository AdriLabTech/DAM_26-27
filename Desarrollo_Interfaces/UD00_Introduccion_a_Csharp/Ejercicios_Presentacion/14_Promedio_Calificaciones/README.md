# Promedio de calificaciones

**Ejercicio 13** de la presentación de la UD00 (Introducción a C# y .NET).

## 📝 Enunciado

Declarar un array con 5 calificaciones decimales `double`.

**Requisitos:** Recorrer el array sumando sus notas y calcular e imprimir el promedio final formateado.

## 📁 Contenido

- `PromedioCalificaciones/Ejercicio13.cs`
- `PromedioCalificaciones/PromedioCalificaciones.csproj`

## 🚀 Ejecución

Necesitas el **SDK de .NET 10**.

```bash
dotnet run --project PromedioCalificaciones
```


## 🧪 Salida

```text
Media: 7,24
```

# Lista de la compra

**Ejercicio 14** de la presentación de la UD00 (Introducción a C# y .NET).

## 📝 Enunciado

Crear una `List<string>` para gestionar artículos de una lista de la compra.

**Requisitos:** Añadir 3 productos, eliminar uno específico por nombre y recorrer la lista resultante.

## 📁 Contenido

- `ListaDeLaCompra/Ejercicio14.cs`
- `ListaDeLaCompra/ListaDeLaCompra.csproj`

## 🚀 Ejecución

Necesitas el **SDK de .NET 10**.

```bash
dotnet run --project ListaDeLaCompra
```


## 🧪 Salida

```text
Leche eliminada: True
Lista final:
- Pan
- Cafe
```

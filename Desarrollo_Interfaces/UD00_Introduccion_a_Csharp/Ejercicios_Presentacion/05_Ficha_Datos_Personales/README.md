# Ficha de datos personales

**Ejercicio 02** de la presentación de la UD00 (Introducción a C# y .NET).

## 📝 Enunciado

Crear variables para almacenar nombre, edad, altura y estado de matrícula.

**Requisitos:** Usar inferencia `var`, formatear la ficha en pantalla con separadores y verificar los tipos.

## 📁 Contenido

- `FichaDatosPersonales/Ejercicio02.cs`
- `FichaDatosPersonales/FichaDatosPersonales.csproj`

## 🚀 Ejecución

Necesitas el **SDK de .NET 10**.

```bash
dotnet run --project FichaDatosPersonales
```


## 🧪 Salida

```text
================================
        FICHA DE DATOS PERSONALES
================================
Nombre      : Lucia
Edad        : 22 anios
Altura      : 1,68 m
Matriculado : True
--------------------------------
Tipos inferidos:
  nombre        -> String
  edad          -> Int32
  altura        -> Double
  esMatriculado -> Boolean
================================
```

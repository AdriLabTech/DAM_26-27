# Vehículo y autobús

**Ejercicio 09** de la presentación de la UD00 (Introducción a C# y .NET).

## 📝 Enunciado

Crear la clase base `Vehiculo` con `Velocidad` y la clase hija `Autobus` con `Capacidad`.

**Requisitos:** Instanciar un objeto `Autobus` y verificar el acceso a miembros heredados y propios.

## 📁 Contenido

- `VehiculoYAutobus/Ejercicio09.cs`
- `VehiculoYAutobus/VehiculoYAutobus.csproj`

## 🚀 Ejecución

Necesitas el **SDK de .NET 10**.

```bash
dotnet run --project VehiculoYAutobus
```
